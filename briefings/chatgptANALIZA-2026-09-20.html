3 · Oportunitatea #1 — Retailer Routing-Guide Preflight CEE

Durerea

Un producător care livrează retaileri mari poate fi penalizat pentru ASN/DESADV greșit, label/carton/pallet neconform, carrier/routing, appointment sau documente. Un exemplu recent de operator descrie comenzi de peste $200k la fiecare trei luni și „huge fines” când fabricile nu respectă cerințele de packing/labeling ale retailerilor. Acesta este anecdotal, nu TAM.

Reddit · manufacturing partner issue

Produsul: înainte de „ship release”, încarci PO + routing guide + ASN/DESADV + carton/pallet labels + packing list + booking. Engine-ul produce PASS / BLOCK / NEEDS EVIDENCE, cu regula exactă, documentul și costul potențial. După livrare, deducțiile se leagă de verdictul pre-shipment pentru a învăța ce reguli chiar costă bani.

Strategul

Arbitrajul este SUA → CEE: în SUA există ecosistem matur de EDI/vendor-compliance; în CEE mulți producători exportă către retaileri vestici, dar rulebook-ul retailerului și ERP-ul fabricii rămân două lumi. ICP: producători RO/PL/CZ/BG cu €5–100M venit și minimum 3 retaileri enterprise.

Marketerul

Nu vindem „AI”. Vindem „trimite-ne ultimele 100 de deductions + routing guide; îți arătăm ce putea fi blocat înainte să plece camionul”. Lead magnet-ul este retrospective chargeback map, apoi preflight pe următoarele 20 shipments.

Financiarul

Model de test: €750–€1.500 retrospective audit; pilot €500–€1.500/lună/site sau success fee pe deductions evitate/recuperate. Primul client poate plăti în 2–4 săptămâni dacă vindem auditul înainte de software. Cost MVP: €150–€600/lună infra/LLM, plus timp de configurare a 2–3 routing guides.

Red-team competitiv — motivul pentru care scorul este doar 7,9

  • Klaimback a lansat în 2026 exact recovery pentru Zalando/Otto/Breuninger și spune că retailerii iau 1–5% din invoice value; costă €2.000/lună + 20% recovery. Este cel mai periculos concurent european.
  • Better EDI face retailer-specific validation și chargeback prevention, dar este orientat puternic spre retailerii SUA.
  • Lotmetric blochează label/shipment errors înainte să iasă din fabrică, inclusiv chargebacks; overlap real.
  • Kill criterion: dacă 5 producători CEE spun că EDI provider-ul/3PL-ul lor face deja preflight complet sau deductions sunt <0,5% din wholesale revenue, abandonăm.

Klaimback · Better EDI · Lotmetric

MVP 4–6 săptămâni

  1. S1: Nuxt 4 + Supabase; Retailer / RuleVersion / PO / Shipment / Evidence / Finding.
  2. S2: import PDF/XLSX/EDI exports; Claude pentru extraction cu provenance; reguli deterministe pentru 20–30 controale.
  3. S3: label/ASN/packing-list cross-check; BLOCK/PASS queue și evidence viewer.
  4. S4: retrospective deduction mapper + cost-at-risk dashboard.
  5. S5–6: n8n email intake/reminders, multi-client workspace, 2 retailer rule packs reale.

Stack: Nuxt/TS, Supabase, n8n, Claude API. RevenueCat nu este necesar pentru B2B web. Stripe ulterior. Speculație explicită: nu avem încă dovadă că producătorii CEE au suficient volum de deductions pentru WTP; acesta este exact lucrul de validat.

6 · Verdictul partenerului — următoarele 48h

Un singur pas: facem un retrospective deduction audit manual pentru 10 producători CEE care livrează retaileri vestici. Cerem doar exportul ultimelor 50–100 deductions/short-pays și un routing guide. GO dacă ≥3 au pierderi contestabile/prevenibile de ≥1% din wholesale invoices și ≥2 acceptă un pilot plătit de minimum €750. KILL dacă deductions sunt rare, sunt aproape toate valide sau EDI/3PL-ul existent previne deja problema. Nu construim dashboard-ul înainte de această dovadă.
