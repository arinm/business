3 · Oportunitatea #1 — EUDAMED Legacy Portfolio Reconciliation CEE

Arbitrajul nu este „copiem un SaaS american”. Este aplicarea modelului asiatic de document automation la un deadline european cu date regulatorii fragmentate.

Durerea și deadline-ul sunt reale

Primele patru module EUDAMED sunt obligatorii din 28 mai 2026. Pentru dispozitivele legacy plasate pe piață înainte de acea dată și care continuă să fie comercializate, autoritatea română confirmă extensia de șase luni pentru UDI/Device registration — adică sfârșitul lui noiembrie 2026. Comisia cere ca producătorii să depună informația UDI/Device pentru produsele introduse pe piața UE.

Comisia Europeană · UDI/Device · ANMDMR România · deadline-uri EUDAMED

Ce construim — și mai important, ce NU construim

Nu: încă un XML generator. EUDAbridge, EUDAMate, EudaMed.com, ACKOMAS, EUDAPrep și Offing acoperă deja data prep, validare, M2M și submissions.

Da: un pre-submission reconciliation layer white-label pentru RA consultancies / authorised representatives din CEE:

  • ingest ERP/Excel + IFU + certificate + existing UDI exports;
  • entity resolution pentru device / Basic UDI-DI / family / legacy ID;
  • conflict detection: denumiri, manufacturer, risk class, certificate, EMDN, status, UDI;
  • provenance per field: „din ce document/pagină vine valoarea?”;
  • READY / CONFLICT / MISSING / NEEDS RA DECISION;
  • export curat pentru instrumentul de submission existent, plus audit packet PDF/CSV.

Strategul de Business

Wedge-ul trebuie vândut către consultantul care gestionează 10–50 de producători, nu către fiecare producător. Astfel obținem distribuție, repetabilitate și date variate fără CAC uriaș. Geografia CEE contează pentru limbă, relații și fragmentarea portofoliilor, nu ca moat tehnic.

Marketerul

Pitch-ul nu este „AI pentru EUDAMED”. Este: „Trimite-ne exportul și documentele. În 24h primești exact ce este gata, ce se bate cap în cap și ce trebuie decis de RA înainte de 28 noiembrie.” Lead magnet: audit gratuit pentru 5 devices, apoi paid sprint.

Financiarul

Model de test: €500–€1.500 per portfolio sprint pentru până la 50 devices; reseller/consultant €199–€499/lună sau €2.000–€5.000/an după validare. Marja poate depăși 80% dacă LLM-ul doar extrage și regulile decisive rămân deterministe / human-approved. Dar deadline-ul creează risc de venit sezonier; trebuie demonstrat use-case-ul post-deadline: change monitoring + Swissdamed/GUDID sync + certificate expiry.

Contra-argumente serioase

  • Concurența este deja mare. EUDAbridge transformă Excel în XML și face validation; EUDAMate curăță ERP exports; EUDAPrep extrage din documente; ACKOMAS oferă master catalog multi-registry; EUDAMED Mapper vinde inclusiv reseller licenses.
  • Deadline business, nu platform business. După noiembrie, urgența scade. Fără post-market/change-monitoring, produsul devine proiect sezonier.
  • Domain expertise. Un senior frontend poate construi workflow-ul, dar deciziile MDR/IVDR nu pot fi lăsate pe Claude. Este obligatoriu un RA partner pentru rule validation.
  • Kill criterion: dacă 5 consultanți spun că problema reală este submission-ul, nu reconcilierea datelor, abandonăm — incumbents au deja submission.

Concurență verificată activ: EUDAbridge · EUDAMate · EUDAPrep · ACKOMAS · Offing · EUDAMED Mapper

MVP 4–5 săptămâni

  1. Săptămâna 1: Nuxt 4 + Supabase Auth/DB/Storage; schema Device / SourceDocument / Claim / Conflict / Decision. Import XLSX/CSV.
  2. Săptămâna 2: Claude API pentru document extraction cu page/source citations; deterministic validation pentru câmpurile selectate; review UI.
  3. Săptămâna 3: reconciliation engine + confidence + provenance; export CSV/XML-compatible mapping, fără submission direct.
  4. Săptămâna 4: multi-client workspace pentru consultanți; n8n pentru reminder/collect supplier docs; audit report.
  5. Săptămâna 5: hardening pe 3 portofolii reale și security/basic GDPR.

Stack: Nuxt/TypeScript, Supabase, n8n, Claude API. RevenueCat nu este necesar pentru web B2B; Stripe ar fi mai potrivit ulterior. Cost MVP: aproximativ €150–€600/lună infrastructură + LLM la volum mic, plus €500–€2.000 pentru consultanță RA/QA dacă nu avem partener. Primul client plătitor: realist 2–4 săptămâni dacă vindem auditul înainte de produs; 6+ săptămâni dacă așteptăm platforma.

4 · Radar România / Europa — două probleme reale

A. Customs packet reconciliation: problema este reală, dar piața este deja prea ocupată

Autoritatea Vamală Română confirmă separarea ENS în ICS2 de NCTS6 pentru opt-out și obligația operatorilor de a avea acces ICS2. Durerea documentelor este reală, dar am găsit exact produsul pe care l-am fi construit: SKAI, Digicust, Balasci, Customs OS, DocuBroker; iar în România, Navlux automatizează deja CMR/order/invoice/ANAF.

Verdict: 6,1/10 — abandonăm varianta generică.

Autoritatea Vamală Română · SKAI · Digicust · Navlux România

B. CPR 2024/3110: producătorii trebuie să urmărească migrarea standardelor, dar și aici există produse directe

Tranziția de la CPR-11 la CPR-24 este per standard armonizat; autoritățile recomandă producătorilor să monitorizeze publicarea noilor specificații deoarece pot fi necesare re-evaluări, DoPC și documentație nouă. Ideea de „transition monitor” părea bună, dar Certivo declară explicit că sincronizează standardele și reassesses entire portfolios; Pelicopy și Vantia automatizează DoP/DoPC.

Verdict: 6,6/10 — problemă reală, wedge insuficient.

6 · Verdictul partenerului — un singur pas în 48h

Obține 3 portofolii EUDAMED reale înainte să scriem produsul

Contactează 10 consultanți MDR/IVDR, authorised representatives sau RA freelancers din România, Polonia, Bulgaria, Cehia cu oferta: „Îți fac gratuit un readiness reconciliation pe maximum 5 devices legacy; primesc Excel + 2–3 documente/device și îți returnez conflict report + evidence map.”

GO: minimum 3 portofolii reale + 2 consultanți care spun că ar plăti ≥€500 per client sau ≥€2.000/an white-label.

KILL: mai puțin de 3 portofolii, sau respondenții spun că EUDAbridge/EUDAMate/EUDAPrep le rezolvă deja 80%+ din problemă.
